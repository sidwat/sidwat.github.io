# Starfield revision

Reference inspected visually: https://openai.com/index/gpt-6-astra-next-generation-work/

Project pages now use a viewport-wide star simulation instead of the rotating spherical particle arrangement. Stars vary in size, warmth and brightness, with rare halos and diffraction rays. Most drift independently for four seconds, gather gradually over eight seconds, hold the project name, and disperse toward distributed positions again. A small distant population remains scattered.

The same damped force integration runs in every phase. The pointer repels nearby stars and gives them a small tangential wake; attraction gradually restores the letters after it leaves. Motion pauses with the existing preference and when the document is hidden. Reduced Motion renders a static word.

The site-wide web is now two faint, irregular orb-web structures anchored near opposite edges, with curved silk strands. Both background canvases clear actual text-line rectangles and controls, leaving open space available without drawing behind the writing. Rectangles refresh on scrolling, resize and content navigation.

Screenshots show drift, assembled NNLF, and pointer displacement. Lint, TypeScript during production build, and project checks in Chromium/WebKit passed. Physics checks verify concentration in the word, displacement by the pointer while assembled, and transparent pixels beneath the heading.

No content or contact configuration changed. This is a visual particle simulation, not an astronomical model.
