# Drafts

The Writer delivers drafts here as `<task-id>-<slug>.md` (e.g. `W-3-hello.md`). Each draft has, in order: the text; the target (a `content/blog/<slug>.md` path, a `lib/content.ts` field, or a `docs/design/copy.md` ID); a fact table with a source for each fact; and the open uncertainties.

Status lives in the draft's first line: `Status: draft | changes requested | approved by owner <date> | published <date>`.

Public repo: drafts are visible to anyone. Never put unapproved confidential material here.
