# Content inbox

Where the owner drops raw material for the Writer, and where the Writer logs its questions and the answers.

**This file is public** (public repo, permanent history). Don't paste anything confidential: unreleased Samsung work, patent details beyond what's already filed and public, private emails, or other people's personal data. If something is sensitive, tell the Tech Lead in conversation instead, and we'll decide whether it can be written down.

## How to add material
Add a new section at the bottom using this template. Rough notes and bullet points are fine.

```markdown
## IN-<n> · <short title> · <date added>
- For task: W-<n> (or "new")
- Target: <page / blog post / contact copy / other>
- Audience: <who should read it>
- Material:
  <paste notes, abstract, links, bullet points>
- May be public? <yes / ask me / no — just context>
- Deadline (if any):

### Questions (Writer)
1. …

### Answers (Owner)
1. …

### Brief (Writer, confirmed by Owner on <date>)
…
```
