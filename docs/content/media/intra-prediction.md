# Intra-frame prediction illustration

Original code-native SVG: public/media/projects/intra-prediction.svg.

Shows a single image with a target block and highlighted decoded reference pixels immediately above and left, feeding a conceptual neural predictor. The output continues the local texture. The illustration deliberately avoids suggesting a block is copied from another frame or a distant image patch. This is a schematic, not an exact architecture or measured prediction result.

The detail page preserves the complete diagram and uses the caption “Illustrative image”. Replaces the flower thumbnail only; no project claims or figures were changed.
