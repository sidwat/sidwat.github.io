Specimen post: how long text sits on the ground

A placeholder article for checking measure, rhythm, code, tables and footnotes on ink and studio. Nothing here is real content.

This paragraph sets the measure. The column is 36rem wide, which is about sixty-four characters at this size, and the text is luma, not muted, because an article is read for minutes rather than glanced at. A link keeps the same colour and gains a solid accent underline; inline code sits on the surface fill with a hairline border.

A long unbroken token must not widen the page: aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa breaks wherever it has to.1

A section heading#

Section headings carry a hairline above them, the same idiom as the ruled lists elsewhere on the site. Lists use the hyphen rule from the Teaching page, in muted rather than line colour so the marker survives on studio:

  • First item, short.
  • Second item, long enough that it wraps onto a second line at the narrowest supported width so the hanging indent is visible.
  • Third item with code in it.
  1. An ordered item.
  2. Another, with a mono muted numeral.
  • A finished task (check mark, not colour alone)
  • An open task

A sub-heading#

A quotation is secondary voice: muted text with an accent rule on the left, no italics.

Result

The code block below breaks out to the frame width and scrolls inside itself. It is a focusable region with a visible ring; the long comment line is deliberate.

// Rate-distortion cost of one candidate mode: lower is better, and lambda sets the exchange rate between bits and error.
export function cost(bits: number, distortion: number, lambda = 0.85): number {
  return distortion + lambda * bits;
}

The numbers below are illustrative. The table sits in its own scroll container and never widens the page.
